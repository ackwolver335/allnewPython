### How Computers think ?

- Below I have a Table structure for how the computer store the data in the memory while working at different data structures.

| Col1 | Col2 |
| ---- | ---- |
| Row1 | Data |
| Row2 | Data |

**Note** : In all the cells, there is some data. Each one can be any character or element or any symbol. And the above data can be of any file, regardless of what can be put inside it.

- There could be any file ex- **sample.txt**, and the data is first read by the computer depending on the size, then its loaded in the memory and after that to the Graphical Screen.

**Sample Program** ( Just an example ) :

```python
a = 2
b = 3
c = a + b

# first the a will be pointed to 2
# then similarly b to 3 and then c to the sum result of a and b after getting it stored into the memory.
```

**Checking if Python is Installed or not ?**

- For Linux users, use the command below :

```bash
python

# if the above command doesn't works due to some system compatibility, use the command given below :
python3
```

- For MAC OS, users use the command given below :

```bash
python3
```

- For Windows users, try the command given below :

```bash
python --version

# for running python terminal IDLE, use the command below :
python
```

- For Testing, if the Python is working correctly, you can try a simple calculation below :

```python
1 + 1

# for exiting Python IDLE, try the command below
exit() or quit()

# there is also a shortcut for exiting Python IDLE
CTRL + D            # for MAC Users
CTRL + Z            # for Windows Users

quit()              # Common for all Operating Systems
```

**Note** : Remember to try this in Python IDLE, for testing if its Terminal is working correclty or not !
